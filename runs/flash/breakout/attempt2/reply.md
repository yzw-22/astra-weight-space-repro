Design: I hand-build a projected-interception policy. Nine hidden units correspond to the nine possible ball rows. Each row unit computes the projected landing column at row 8 using the ball column, horizontal direction inferred from the trail, the paddle column, and a boundary correction at the side walls. The unit is gated by a large positive constant only on that ball row, so exactly one row unit is active; the others saturate to \(-1\). The second hidden layer nearly passes these signals, and the output layer cancels the eight inactive units and selects left/right when the projected column is left/right of the paddle. If the projection equals the paddle position, all directional logits are zero while four harmless no-op actions have a positive bias, so the policy holds still (and catches centrally).
